# Data_Analysis_Launchspring

# Motive: 
To analyse a movie ratings dataset 

# ⚒️Tools used: 
a) Python: For Pre-processing the dataset
b) Power Bi: For Visualization and Dashboard 
c) Power Point: For Final Report and presentation of the project 

# Key Insights:
1. Drama has emerged as the best genre
2. Average ratings was highest in the years 1947 & 1956: 8.95
3. The average votes has seen a down-trend since the year 1975
4. The lowest number of average rating is in the current year 2025: 5.9
5. Higher rating meant higher number of votes received
